# Contributing to Exo Cinema

Thanks for helping. Bug reports, ideas and clearer wording are welcome.

## Before you start

- **Report a problem or suggest a feature** with the [issue forms](https://github.com/UhhErix/ExoCinema/issues/new/choose). Issues are public: leave out your server's address, your user name and anything else personal.
- **Security problems** go [privately](https://github.com/UhhErix/ExoCinema/security/advisories/new), not in an issue.

## What you agree to

Exo Cinema is not open source (see [LICENSE](LICENSE)). When you send a contribution, such as a pull request or a patch, you grant the copyright holder a perpetual, worldwide, royalty-free and irrevocable license to use, change and distribute it as part of Exo Cinema under any terms. Send only work you have the right to give.

## Pull requests

This repository holds Exo Cinema's releases and its pages (this guide, the README, help, privacy and the notices); the app's source isn't public, so pull requests are for these pages.

- Keep one change per pull request, and say what it fixes and how you checked it.
- Match the code around it: its naming, its comments and Exo's design (Exo Launcher's look is the standard).
- Words in the app are plain and short, in Exo's voice. No hint lines under controls.
